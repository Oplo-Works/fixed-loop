# fixed-loop

Post-training Gemma 4 E4B into an offline coding agent: a fixed loop — reproduce → localize → patch → verify — inside a hermetic sandbox. No internet, no proprietary model, one solo practitioner on Kaggle's free GPU tier.

## Paper

[Small Model, Fixed Loop, Measured Iterations](PAPER.md) — a design and evaluation protocol, written for the Paper Track of the [Gemma 4 Developer Agent Competition](https://www.kaggle.com/competitions/gemma-4-developer-agent-paper) on Kaggle. The build has not run yet; quantities to be measured are marked `[TO BE MEASURED]` in the paper.

## Status
